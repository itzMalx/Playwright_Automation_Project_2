# 📖 Project Overview

This project is an **end-to-end web automation framework** developed using **Playwright with TypeScript and Cucumber BDD**.

The framework follows the **Page Object Model (POM)** design pattern and focuses on building a reusable, maintainable, and scalable automation solution for web application testing.

It includes:

- End-to-end web automation
- BDD-based test scenarios
- Page Object Model
- Positive and negative test scenarios
- Reusable automation methods
- Test hooks
- Environment configuration
- Allure reporting
- Jenkins CI/CD integration
- GitHub-based collaboration

---

# 🎯 Project Objectives

- Automate critical application workflows
- Reduce repetitive manual testing
- Implement BDD using Cucumber
- Follow Page Object Model architecture
- Create reusable automation components
- Validate positive and negative scenarios
- Generate detailed execution reports
- Integrate automated tests with Jenkins
- Maintain source code using Git and GitHub
